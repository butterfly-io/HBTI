# HBTI Test 运行帮助

这个项目现在已经调整为标准的 Vite + React 项目，可以直接在本地运行。

## 运行环境

- Node.js 18 及以上版本
- npm

## 第一步：进入项目目录

在终端里切换到项目根目录：

```bash
cd c:\Users\yangb\Desktop\竞赛\hbti-test
```

## 第二步：安装依赖

第一次运行项目时，先安装依赖：

```bash
npm install
```

如果你之前已经成功安装过依赖，这一步可以跳过。

## 第三步：启动开发环境

执行下面的命令：

```bash
npm run dev
```

启动成功后，终端会显示一个本地访问地址，通常类似：

```text
http://localhost:5173/
```

如果 `5173` 端口被占用，Vite 会自动切换到其他端口。你只需要打开终端实际显示的地址即可。

## 第四步：在浏览器打开项目

把终端输出的本地地址复制到浏览器中打开，就可以看到页面。

目前项目的主流程是：

- 进入首页
- 点击开始测试
- 完成题目选择
- 进入结果页

## 停止运行

如果你想停止开发服务器，在终端里按：

```bash
Ctrl + C
```

## 生产构建

如果你想确认项目可以正常打包，执行：

```bash
npm run build
```

打包成功后，会在根目录生成 `dist` 文件夹。

## 本地预览构建结果

如果你想用接近线上环境的方式预览构建结果，执行：

```bash
npm run preview
```

终端会输出一个本地地址，打开即可查看打包后的页面。

## 常见问题

### 1. 运行时提示 `npm` 不是内部或外部命令

说明 Node.js 可能还没有安装，或者没有加入系统环境变量。先安装 Node.js，再重新打开终端。

### 2. 运行时提示依赖缺失

先重新执行：

```bash
npm install
```

### 3. 端口被占用

这是正常情况。Vite 会自动换一个端口，直接使用终端里新显示的地址即可。

### 4. VS Code 里 CSS 还有 Tailwind 规则提示

这个项目已经做过工作区设置处理，不影响实际运行和打包。如果构建命令能通过，就说明项目本身没有问题。

## 当前可用命令

```bash
npm run dev
npm run build
npm run preview
```
